# Implementation Plan: Google Ads Integration

**Branch**: `026-google-ads-integration` | **Date**: 2026-08-01 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/026-google-ads-integration/spec.md`

---

## Summary

Integrate Google AdSense into Ngoma using a **Hybrid model**: Google Auto ads enabled globally for ML-optimised fill, plus four manually placed `<ins>` ad units at the ad-gate modal, Discover page, Track page, and Artist Profile page. The backend `AdsConfig` is extended with a `googleAdsEnabled` flag and the gate default is raised to 30 seconds. All changes are purely additive — no new database tables or migrations required.

---

## Technical Context

**Language/Version**: TypeScript on Node.js 20+ (api + client workspaces)

**Primary Dependencies**:
- API: NestJS 11+, TypeORM, @nestjs/jwt, class-validator
- Client: React 18, Vite, Tailwind CSS, shadcn/ui, TanStack Query

**Storage**: `PlatformSettings.adsConfig` JSONB column (existing) — additive JSON key, no DDL migration

**Testing**: Jest (api), Vitest (client)

**Target Platform**: Web (mobile-first SPA + REST API)

**Performance Goals**: Ad unit `<ins>` tags push synchronously on mount; no blocking requests on the critical render path. AdSense script loads async.

**Constraints**: Follow `mako/api` module layout; all routes under `/api/v1/`; no Prisma/Next.js/Express. New env vars all prefixed `VITE_ADSENSE_*`.

**Scale/Scope**: Extends existing `ads` module and `AdminAdsPage`. No new NestJS module needed.

**Reference**: `research.md`, `data-model.md`, `contracts/api-contracts.md`

## Phase 1: Design

### Backend Changes

#### `api/src/common/ads-config.util.ts`

Add `googleAdsEnabled: boolean` to `AdsConfig` type and `DEFAULT_ADS_CONFIG`. Raise `gateSeconds` default from `5` to `30`. Update `mergeAdsConfig` to include the new field.

#### `api/src/modules/ads/dto/update-ads-config.dto.ts`

Add `@IsOptional() @IsBoolean() googleAdsEnabled?: boolean` field.

#### `api/src/modules/ads/ads.service.ts`

- `updateConfig`: persist `googleAdsEnabled` from DTO.
- `getPublicConfig` / `getConfig`: return `googleAdsEnabled` in the response.

### Client Changes

#### `client/index.html`

Inject AdSense async script in `<head>`:

```html
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=%VITE_ADSENSE_PUBLISHER_ID%" crossorigin="anonymous"></script>
```

Vite replaces `%VITE_ADSENSE_PUBLISHER_ID%` at build time. When the variable is empty, the script tag is harmless (loads no-op).

#### `client/src/components/ads/GoogleAdUnit.tsx` (NEW)

```tsx
// Reusable wrapper — renders null when publisher ID or slot ID is absent
// or when googleAdsEnabled is false from platform config.
// Calls (window.adsbygoogle = window.adsbygoogle || []).push({}) in useEffect.
// Catches all errors silently to ensure zero console errors with ad-blockers.
```

Props: `slotId: string`, `format: 'auto' | 'rectangle' | 'leaderboard'`, `className?: string`

Reads `VITE_ADSENSE_PUBLISHER_ID` from `import.meta.env`. Returns `null` if absent.

#### `client/src/hooks/useAds.ts`

Extend `AdsConfig` type to include `googleAdsEnabled: boolean`. No other hook changes needed.

#### `client/src/components/ads/AdGateModal.tsx`

Replace the static `<img>` creative display with:

```tsx
{googleAdsEnabled && slotGate ? (
  <GoogleAdUnit slotId={slotGate} format="rectangle" />
) : (
  // existing custom creative <img> fallback
)}
```

`googleAdsEnabled` and `slotGate` come from the `useAdsConfig()` hook and env var respectively.

#### Page-level ad placements

Each of the three ambient pages gets one `<GoogleAdUnit>` inserted:

| Page | Slot env var | Format | Position |
|------|-------------|--------|---------|
| `DiscoverPage.tsx` | `VITE_ADSENSE_SLOT_DISCOVER` | leaderboard | Between hero and music grid |
| `TrackPage.tsx` | `VITE_ADSENSE_SLOT_TRACK` | rectangle | Below action buttons |
| `ArtistProfilePage.tsx` | `VITE_ADSENSE_SLOT_ARTIST` | leaderboard | Between header and tracklist |

#### `client/src/pages/ArtistDashboardPage.tsx`

Add an "Ad-supported" badge on free track rows. Badge renders only when `pricingType === 'FREE'`. Tooltip text: "This track is free for fans. Ad revenue helps sustain the platform."

#### `client/src/pages/AdminAdsPage.tsx`

Add a new Card section **"Google AdSense"** displaying:
- Publisher ID status (configured if `VITE_ADSENSE_PUBLISHER_ID` is set, else "Not configured")
- `googleAdsEnabled` toggle (calls existing `useUpdateAdsConfig` mutation)
- Setup instructions when not configured
